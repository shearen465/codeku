# codeku
Saya membuat sebuah folder bernama codeku yang berisi beberapa file program, seperti fibo.cpp dan assignment.cpp. Setelah itu, saya membuka terminal langsung dari folder tersebut dan menginisialisasi Git menggunakan perintah git init. Kemudian saya menambahkan file-file tersebut ke dalam repository lokal, melakukan commit awal, dan menghubungkannya dengan repository GitHub yang sudah saya buat. Setelah file berhasil di-push ke GitHub, saya membuat branch baru untuk mengembangkan fitur tambahan. Di branch tersebut saya melakukan perubahan pada salah satu file, kemudian commit kembali. Setelah perubahan selesai, saya kembali ke branch utama (main) dan melakukan merge dari branch baru yang telah saya buat. Semua proses tersebut dilakukan menggunakan perintah Git melalui terminal di MacBook. Dengan cara ini, saya bisa mengelola versi kode secara lebih terstruktur dan rapi melalui GitHub.
